# IDELUXE STUDIO V5

Новая версия сайта платформы монтажёра IDELUXE (IDELUXE — никнейм одного человека, не школа и не команда). Сейчас здесь готов лендинг: стиль, видео, окно редактора и плеер шоурила перенесены из v4, космический фон (звёзды и планета) и 3D-декор сделаны заново. Структура сделана заново, под рост проекта.

Стек: Next.js 16 (App Router, Turbopack) · React 19 · Tailwind CSS 4 · TypeScript 5.9 · lucide-react.

## Быстрый старт

```bash
npm install
Copy-Item .env.example .env.local   # bash: cp .env.example .env.local
npm run dev                         # http://localhost:3000
```

Без ключей всё работает, ИИ-ассистент отвечает подсказкой о настройке.

Проверки: `npm run lint`, `npm run typecheck` (сам генерирует типы маршрутов), `npm run build`. `npm run check` = lint + typecheck.

## Структура

```
src/
├─ app/                 маршруты: только сборка страниц, без логики
│  ├─ layout.tsx        html, шрифты (fonts.ts), метаданные, SiteShell
│  ├─ page.tsx          лендинг → features/landing
│  ├─ api/chat/         ИИ-ассистент (стриминг)
│  ├─ login             форма входа/регистрации (пока только дизайн, features/auth)
│  ├─ pricing, learn, resources, legal/*   заглушки «В работе»
│  └─ robots.ts, sitemap.ts, not-found.tsx
├─ config/              техническое: routes, navigation, site, media, env, env.server
├─ content/             тексты и данные: landing (FAQ, «Для кого», клиенты…), pack, tutorial-categories
├─ styles/              дизайн-система: tokens → animations → base → components → effects
├─ components/
│  ├─ ui/               примитивы: AppTile, SectionHeading, BackgroundVideo, ComingSoon, Avatar…
│  ├─ layout/           SiteShell, header/ (шапка, мобильное меню, меню Telegram), footer, HashLink
│  └─ icons.tsx         LogoMark, TelegramIcon
├─ features/            самостоятельные модули, у каждого index.ts — публичный API
│  ├─ landing/          landing-page.tsx, decor.ts, sections/<блок>/<блок>-section.tsx
│  ├─ backdrop/         космос: звёздное небо (canvas 2D) и планета (WebGL)
│  ├─ decor/            парящие 3D-объекты (WebP-рендеры), глубина резкости, пресеты внутренних страниц
│  ├─ reel/             плеер шоурила, кнопка, подсказка «можно кликнуть»
│  ├─ chat/             виджет ассистента, системный промпт (server-only)
│  └─ pack/             карточка IDX PACK
├─ lib/                 utils (cn), format, video-hold, hooks/, server/ (rate-limit, client-ip, request)
└─ types/               общие типы (SessionUser)
```

Правила, которые держат структуру:

- Пути страниц и якоря лендинга — только из `config/routes.ts`, меню и футер — из `config/navigation.ts`. Строк вида `"/pricing"` в компонентах нет.
- Тексты, цифры пака, FAQ, контакты правятся в `content/*` и `config/site.ts`. Ассистент читает те же файлы, поэтому его ответы совпадают с сайтом.
- Фича импортируется снаружи через свой `index.ts`. Серверные файлы (`*.server.ts`, `system-prompt.ts`, `lib/server/*`) помечены `import "server-only"`: сборка упадёт, если их подтянет клиентский компонент.
- Цвета, шрифты и анимации — токены в `styles/tokens.css`. Классы `glass`, `btn-*`, `section`, `reveal` и т. д. — в `styles/components.css` и `styles/effects.css`.
- Стекло (`glass`) как у шапки в развёрнутом виде наверху страницы: лёгкая тёмная заливка поверх сильного размытия, светлее плавающей шапки. `glass-strong` (плотнее) — только для панелей поверх текста, сейчас это ассистент. Два правила, иначе размытие пропадает:
  - в CSS пиши только `backdrop-filter` без `-webkit-` (префикс для Safari добавит сборка; если написать оба, Chrome остаётся без размытия);
  - `reveal` и другие эффекты с прозрачностью или фильтром вешай на саму карточку, а не на её обёртку.

### Как добавить

- **Блок лендинга**: `features/landing/sections/<name>/<name>-section.tsx` с классом `section`, при необходимости id из `landingAnchors` и пункт в `mainNav`. Подключить в `landing-page.tsx`, 3D-объекты для него — в `features/landing/decor.ts`.
- **Страницу**: путь в `config/routes.ts`, файл `app/<path>/page.tsx`, при публичной странице — строка в `app/sitemap.ts`. Для заглушки есть `ComingSoon`.
- **Новую фичу**: папка `features/<name>/` со своим `index.ts`.
- **Авторизацию**: форма на `/login` уже свёрстана (`features/auth/auth-form.tsx`: вход, регистрация, показ пароля, согласие с офертой, кнопка Telegram), но сейчас никуда ничего не отправляет и только показывает подсказку. Подключи настоящий вызов в её `onSubmit`, на сервере в `app/layout.tsx` получи пользователя и передай в `<SiteShell user={…}>` (тип `types/session.ts`). Шапка уже умеет показывать аватар и ссылку на профиль. Если части страниц нужен другой каркас, перенеси `SiteShell` в `app/(site)/layout.tsx`.
- **Запуск IDX PACK 3D**: сейчас это заблокированная карточка `features/pack/pack-locked-card.tsx` (размытое содержимое, замок, «Скоро», ссылка на Telegram-канал) — полосой под паком на лендинге и рядом с ним на `/pricing`. Когда пак выйдет: цены и `available: true` в `content/pack.ts`, а заблокированную карточку замени обычной. `PackCard` сейчас показывает только IDX PACK, ему понадобится проп с id товара и своим составом.

## Видео

Файлы лежат в `public/videos`, пути и подписи — в `config/media.ts`.

| Файл | Где | Что это |
| --- | --- | --- |
| `reel-teaser.webm/.mp4/.jpg` | монитор в окне редактора | 16 с шоурила (27,3–43,3 с), без звука |
| `editor-thumbs.jpg` | миниатюры клипов на таймлайне | 34 кадра 112×63 в строку |
| `about-loop.webm/.mp4/.jpg` | «Обо мне», парящий экран | «о нас» без звука, 6:5 |
| `back.webm/.mp4/.jpg` | фон финальной карточки | бесшовный луп, перекрашивается (`tone="duotone"`) |
| `showreel-1080.mp4`, `showreel-720.mp4`, `showreel.jpg` | плеер шоурила | полный шоурил со звуком |
| `about-full.mp4`, `about-full.jpg` | плеер «Как устроен IDX PACK» | «о нас» со звуком |

- Фоновые лупы грузятся при подходе к экрану, вне экрана и пока открыт плеер стоят на паузе (`lib/video-hold.ts`). При «Уменьшить движение» и экономии трафика показывается только постер.
- Склейки на таймлайне редактора совпадают с реальными склейками `reel-teaser` и заданы в `features/landing/sections/hero/editor/showreel-edit.ts`. При замене фрагмента их нужно найти заново (ffmpeg: `select='gt(scene,0.28)'`) и обновить `clips`, а при другом числе миниатюр — `THUMB_TILES`.
- Исходники рендеров (сотни МБ) в проект не скопированы: они остались в `../media-source` проекта v4. Команды ffmpeg для пережатия — в README v4, раздел 5.
- Трафик: первый экран ≈ 3,3 МБ, полный шоурил 38 МБ (1080p) или 18 МБ (720p). Когда посещаемость вырастет, вынеси `public/videos` в CDN и задай `NEXT_PUBLIC_MEDIA_URL`.

## Космический фон

`features/backdrop`: фиксированный слой за всем сайтом.

- Звёзды и редкий метеор — `starfield.ts` (canvas 2D).
- Планета — `planet.ts` и `planet-shaders.ts` (WebGL 1). Её край выходит снизу экрана, солнце спрятано за ней: светится только тонкий серп у края и атмосфера, остальное ночная сторона с огнями городов. Фон остаётся тёмным, текст поверх читается. Карта поверхности (материки, облака, города) считается один раз при загрузке, по полосам за несколько кадров. Дальше каждый кадр — две выборки из текстуры на пиксель.
- Планета медленно вращается сама и заметно быстрее при прокрутке, облака идут чуть быстрее поверхности (`space-scene.tsx`: `IDLE_SPIN`, `SCROLL_SPIN`).
- Что настраивается в `planet.ts`: высота края `PLANET_LIMB`, размер в `planetGeometry`, наклон оси `TILT`/`ROLL`, направление на солнце `SUN`. Цвета и яркость — в `PLANET_FRAG`.
- Без WebGL рисуется плоский силуэт с ореолом, при «Уменьшить движение» — один неподвижный кадр. Пока открыт плеер шоурила, анимация стоит (`lib/video-hold.ts`).

## 3D-декор

Объекты по бокам — заранее отрендеренные прозрачные WebP из `public/decor` (17–45 КБ), WebGL ради них в браузере не запускается. Набор: `play`, `keyframe` (ключ After Effects), `lens`, `wave` (звук), `sparkle` (иконка ассистента) и абстрактные `knot`, `cube`, `asterisk`. Первые пять рендерит `tools/decor-render` с общим светом под фон: контровой сверху-сзади, как солнце за планетой, розовый и фиолетовый по бокам, фиолетовый отсвет снизу. `knot`, `cube` и `asterisk` — исходные рендеры из v4, в `scene.js` их нет.

Каждый объект парит (два цикла `levitate` и `sway`) и живёт в глубине кадра (`features/decor/decor-3d.tsx`):

- `depth` ≈ 0.6 — плоскость фокуса, где контент: объект резкий.
- Меньше — дальше за контентом: мельче по параллаксу, размыт, тусклее и серее.
- Больше 0.85 — передний план. Объект рисуется поверх контента, сильно размыт и затемнён, держится у края экрана и не заходит на колонку текста. Показывается только на экранах от 1280 px.
- Ближние объекты обгоняют прокрутку, дальние отстают. У верхнего края все немного теряют фокус.

Расстановка: на лендинге — `features/landing/decor.ts`, на внутренних страницах — `features/decor/presets.ts`. Параметры объекта: сторона и отступ `x` (отрицательный — частично за краем), `inset` (сдвиг к контенту на широких экранах), `size`, `rotate`, `depth`, `blur` (вместо размытия по глубине), `mobile`.

### Перерендер и новые объекты

Модели, материалы и студийный свет — в `tools/decor-render/scene.js` (three.js). Рендер идёт в headless Edge (или Chrome через `BROWSER_PATH`), у инструмента свои зависимости, в сайт они не попадают:

```bash
npm install --prefix tools/decor-render
npm run render --prefix tools/decor-render              # все объекты
npm run render --prefix tools/decor-render -- play lens # выборочно
```

Скрипт пишет `public/decor/<name>.webp` и `tools/decor-render/preview.png` (все объекты на фоне сайта), а в консоль выводит размеры. Новый объект: функция в `objects` в `scene.js`, затем имя и размер в `DecorName` и `INTRINSIC` (`decor-3d.tsx`). После перерендера увеличь `DECOR_VERSION` там же: браузеры держат `/decor` в кэше неделю.

## ИИ-ассистент

Окно чата вырастает из кнопки в правом нижнем углу и сворачивается обратно в неё (класс `pop-panel` в `styles/components.css`). Закрывается той же кнопкой, клавишей Escape или кликом в любом месте страницы, кроме кнопок «Спросить ассистента» (`OpenChatButton`).

Любой OpenAI-совместимый API, по умолчанию DeepSeek. Ключ и модель — в `.env.local` (см. `.env.example`). Промпт собирается в `features/chat/system-prompt.ts` из `content/*` и `config/site.ts`: роль, стиль, границы тем, запрет помощи со взломом ПО.

`/api/chat` открыт без авторизации. Защита: проверка Origin (чужие сайты не могут вызвать его из браузера), лимит размера тела и сообщений, дневной лимит на IP (`CHAT_DAILY_LIMIT`). Лимит считается в памяти процесса: подходит для одного сервера (`npm start` на VPS). На serverless или нескольких инстансах счётчики не общие и сбрасываются при перезапуске, поэтому до публичного запуска счётчик нужно перенести в общее хранилище (Postgres, Redis) за тем же интерфейсом `consumeDailyQuota`.

## Чего пока нет

Перенесён только лендинг. Ссылки на тарифы, туториалы, ресурсы и юридические документы ведут на заглушки «В работе». «Тарифы» показывают карточки IDX PACK и IDX PACK 3D («Скоро») и кнопку Telegram-бота, вход — форму без отправки. Авторизации, оплаты, базы данных и каталога туториалов в V5 нет, их можно переносить из v4 по одной фиче в `features/`.

Проверено: `lint`, `typecheck`, `build`; в браузере на 1440×900 и 390×844 — все блоки лендинга, плеер шоурила (пауза фона при открытом плеере), чат в демо-режиме, мобильное меню, заглушки. Фон с планетой и новый декор — на 1440×900 и 390×844, в режиме «Уменьшить движение» и на внутренней странице.
